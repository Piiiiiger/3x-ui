description: "Clash rule templates plans share: rule lines, a YAML document
  (whose proxy groups list __PROXY_NODES__ where the subscription's nodes go, or
  select them with a filter) or one HTTPS URL. A variant (baseId set) holds only
  what it changes in a full YAML template, as a Clash Verge Merge document: a
  top-level key replaces the base's, prepend-rules / append-rules and
  prepend-proxy-groups / append-proxy-groups add before or after the base's
  lists. A plan names its template by id; plans with templateId 0 and clients
  without a plan get the default template. Each content change is kept as a
  version, the newest 20 per template."
