代理面板是高价值目标。几层加固措施就能带来很大改善。

## 面板加固

- 强而唯一的凭据，并启用**双因素认证**（TOTP）。
- 使用非默认的面板端口，以及一个长且随机的 Web 根路径。
- 为面板启用 TLS（直接启用，或通过[反向代理](/docs/operations/reverse-proxy)）。
- 内置的**登录限制器**会在某个 IP/用户名于 5 分钟内连续 5 次登录失败后将其封锁
  （封锁 15 分钟），并且面板可以将自身的出站流量经由某个 outbound 路由出去。

完整的检查清单请参见[首次登录](/docs/guide/first-login)。

## IP 限制

为每个客户端设置 **IP 限制**（参见[客户端](/docs/config/clients)），限制它同时在线的网络数，
按面板管理的所有服务器合计：一个 IPv4 地址算一个网络，一个 IPv6 /64 也算一个。

限制由面板自己执行，不需要 Fail2ban，也不需要防火墙规则。

- 客户端超出限制时，最久未活动的网络会对该客户端封禁一段时间（面板设置中的
  **IP 限制封禁时长**，默认 **30 分钟**）。封禁是为该客户端服务的每台服务器 Xray 配置里的
  一条路由规则，生效时不重启 Xray；同一地址后的其他用户不受影响。
- 面板自己的服务器（每个节点的地址，以及其 agent 连接面板时的地址，因此中转服务器也包括
  在内）、**IP 限制白名单**和内网地址永远不会被计入或封禁。
- 客户端的 IP 日志会标出豁免的地址和正在生效的封禁，并可提前解除封禁。每次封禁和解除也会
  写入 `/var/log/x-ui/3xipl-banned.log`（`x-ui banlog`）。

封禁开始时已建立的连接会持续到自行关闭；来自被封网络的新连接会被拒绝。

## 防火墙

只开放你实际使用的端口：SSH、面板端口、订阅端口以及你的入站端口。`x-ui` 菜单
（**22 — Firewall Management**）封装了 `ufw`，或者你也可以在此生成规则：

</Callout>

## 网络调优（BBR）

`x-ui` 菜单（**25 — Enable BBR**）用于切换 Google 的 BBR 拥塞控制算法
（`net.ipv4.tcp_congestion_control = bbr`、`net.core.default_qdisc = fq`），它在拥塞链路
上通常能提升吞吐量。

## 保持更新

定期更新 3x-ui 和 Xray-core——安全修复会随新版本发布。请关注
[发布页面](https://github.com/MHSanaei/3x-ui/releases)，并参见
[更新与卸载](/docs/guide/update-uninstall)。
